## 行程概览

为吃而去，天河潭只占半天。住宿锁定喷水池老城中心，步行可达民生路、陈氏人家、贵厨。地铁刷云闪付，不用单独买票。

| 日期     | 天数  | 行程                               | 交通          | 重点                     |
| -------- | ----- | ---------------------------------- | ------------- | ------------------------ |
| 5月27日  | Day 1 | 成都东 → 贵阳北 → 喷水池           | 高铁 3h17min + 地铁 30min | 陈氏人家豆米火锅、民生路、青云集市 |
| 5月28日  | Day 2 | 天河潭 → 回城继续吃                 | 地铁往返 2×50min | 天河潭溶洞、铁签牛肉/烙锅 |
| 5月29日  | Day 3 | 喷水池 → 贵阳北 → 成都东           | 地铁 30min + 高铁 3h39min | 最后一顿正餐、晚七点半到家 |

---

## 出行提示

**火车票** — 往返均提前在 12306 购票，旺季（5月底）建议尽早买。

**地铁** — 贵阳地铁刷**云闪付**乘车码，比买票方便。喷水池站是 1 号线 + 2 号线换乘站，去哪都方便。

- **去贵阳北站**：1 号线直达（往窦官方向），约 30 分钟
- **去天河潭**：1 号线 → 望城坡换乘 S1 线（往皂角坝方向），约 50 分钟

**天气** — 5 月底贵阳 18~28℃，偶有阵雨，带把伞即可，短袖 + 薄外套够用。

**必备物品**
- 身份证
- 手机（云闪付、12306、地图）
- 伞（贵阳天说变就变）
- 消食片（你懂的）

## Day 1 — 5月27日 · 成都 → 贵阳，老城逛吃

上午高铁到贵阳，中午入住喷水池，下午扫小吃街，晚上正餐 + 宵夜。

| 时间     | 行程                     | 备注                                       |
| -------- | ------------------------ | ------------------------------------------ |
| 07:30    | 起床                     | 收拾出门                                   |
| 08:00 前 | 坐地铁去成都东站         | 预留安检进站时间，提前 30min 到站          |
| **08:54** | **G2801 发车**          | 成都东 → 贵阳北，3h17min，二等约 ¥282      |
| 12:32    | 抵达贵阳北站             | —                                          |
| 12:35    | 坐 1 号线去喷水池        | 往窦官方向，约 30min（含步行等车）         |
| 13:05    | 入住 7 天酒店            | 喷水池 C 口步行 2min，放行李                |
| 13:15    | 🫘 陈氏人家豆米火锅      | 富水北路园通街 105 号，步行 5min，11:00 已营业 |
| 14:30    | 逛喷水池商圈             | 太平路网红街、民生路小吃街，边走边吃       |
| 15:00    | 小吃时间                 | 安顺裹卷、小豆腐、黄瓜冰浆                  |
| 18:00    | 🦑 大健鱿鱼炖土鸡        | 鹏哥推荐，打车或地铁前往                    |
| 20:00    | 青云集市                 | 逛夜市，烤鱼、烙锅看肚子余量                |

**住宿** — 7 天酒店（贵阳喷水池地铁站民生路好吃街店），云岩区夏状元街 35 号，C 口步行 2min。2025 年新开，评分 4.6。27 号入住 29 号离开。

**美食** — 豆米火锅（午餐）、鱿鱼炖土鸡（晚餐）、民生路 + 青云集市小吃

## Day 2 — 5月28日 · 天河潭半日 + 回城吃

天河潭 15km²，核心区（水溶洞游船 + 旱洞 + 瀑布）3-4 小时玩完。早上自然醒，吃完早饭出发，下午两三点就回来了，剩下时间继续找吃的。

| 时间        | 行程                   | 备注                                  |
| ----------- | ---------------------- | ------------------------------------- |
| 08:30       | 自然醒，早饭           | 肠旺面 or 老贵阳素粉 or 糯米饭（路边找人多的小店） |
| 09:30       | 喷水池站出发           | 1 号线（往小孟工业园方向）→ 望城坡    |
| 09:40       | 望城坡换乘 S1 线       | 往皂角坝方向，等车约 5-7min           |
| 10:20       | 抵达天河潭站           | A1/A2 口出站，步行 300m 到景区入口    |
| 10:30       | 天河潭游玩             | 套票 ¥75（水溶洞游船 + 旱洞 + 观光车） |
| 10:30-11:00 | 水溶洞（崆灵洞）       | 乘船游览，约 20min                     |
| 11:00-12:00 | 旱洞（银河宫）         | 步行游览，约 1h                        |
| 12:00-13:00 | 钙化滩瀑布、卧龙湖     | 拍照 + 闲逛                           |
| 13:00       | 景区午饭               | 门口有小吃摊和简餐，随便对付           |
| 14:00       | 原路返回               | S1 线 → 望城坡 → 1 号线 → 喷水池       |
| 15:00       | 回到喷水池，休整       | 歇一歇，消消食                         |
| 18:00       | 🍖 马老三铁签牛肉 或 大胖刘烙锅 | 吃一顿                            |

**车程** — 地铁往返各约 50min，天河潭站出站即景区

**美食** — 早餐粉面、天河潭简餐、晚上铁签牛肉/烙锅

> **可选**：天河潭回程可顺路去青岩古镇（需 S1 线折返 + 打车），吃青岩猪脚 + 小豆腐。但加上天河潭一天会比较赶，如果对溶洞兴趣不大可以砍掉天河潭直接去青岩。

## Day 3 — 5月29日 · 午饭后返程

最后半天，早上睡到自然醒，吃个地道早饭，中午认真吃一顿。下午去贵阳北站，晚上七点半到成都东。

| 时间        | 行程                   | 备注                                  |
| ----------- | ---------------------- | ------------------------------------- |
| 09:00       | 自然醒，早饭           | 遵义豆花面 or 湖南面 or 水城羊肉粉     |
| 10:00       | 逛甲秀楼               | 打车 10min，逛半小时                   |
| 10:45       | 返回喷水池             | —                                     |
| 11:00       | 🍲 最后一顿正餐        | 贵厨酸汤牛肉 or 辣子鸡火锅 or 虾酸火锅（看前两天哪些没吃到） |
| 13:30-14:00 | 回酒店取行李，退房     | 时间充裕，不用赶                       |
| 14:15       | 出发去贵阳北站         | 1 号线直达（往窦官方向），约 30min     |
| 14:45       | 抵达贵阳北站           | 预留安检进站                           |
| **15:50**   | **D968 发车**          | 贵阳北 → 成都东，3h39min，二等约 ¥260   |
| 19:29       | 抵达成都东站           | 晚上七点半，不算太晚 ✅                |
| 19:40       | 坐地铁回家             | —                                      |

**备选** — G2890（贵阳北 15:42 → 成都东 19:45），如果 D968 候补不到就买这个，时间差不多。

**美食** — 粉面早饭 + 最后一顿火锅大餐
